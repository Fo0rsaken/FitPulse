# FitPulse — Адаптивное приложение для тренировок

Современное адаптивное веб-приложение (PWA) для домашних и силовых тренировок с иллюстрациями упражнений, интервальными таймерами, конструктором своих программ, календарём прогресса и облачным бэкапом.

## Возможности

- **6 готовых программ тренировок:** домашние без инвентаря, HIIT/Табата, силовая с гантелями (учёт подходов, повторений и веса), пресс и кор, экспресс-зарядка 7 минут, растяжка и мобильность.
- **Каталог из 12 упражнений с иллюстрациями:** фильтры по группам мышц и инвентарю, пошаговая техника, частые ошибки, дыхание и быстрый запуск подхода с таймером.
- **Интерактивный плеер тренировки:** круговой SVG-таймер, фазы подготовки/работы/отдыха, звуковые сигналы (Web Audio API), опциональная голосовая озвучка на русском (Web Speech API), режим повторений с записью весов.
- **Свободный интервальный таймер:** пресеты Табата 20/10, HIIT 40/20, EMOM 60/0, силовой отдых 90с + точная настройка раундов.
- **Конструктор своих тренировок:** создание, редактирование и сохранение собственных программ.
- **Прогресс и календарь:** серия дней, статистика, календарь активности, график за 7 дней, история тренировок.
- **Хранение и облачный бэкап:** локальное сохранение в браузере, экспорт/импорт JSON (удобно для Google Drive) и опциональная синхронизация между ПК и телефоном через приватный GitHub Gist.
- **Адаптивный дизайн + темы:** тёмная и светлая темы, удобная мобильная нижняя навигация и десктопный сайдбар.

## Запуск на GitHub Pages

Приложение состоит из чистых статических файлов (`index.html`, `css/`, `js/`, `assets/`, `manifest.json`) и не требует сборки. Достаточно включить **Settings → Pages → Deploy from a branch (`main` / `root`)**.
